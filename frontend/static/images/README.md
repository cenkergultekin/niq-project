# NIQ icon

Provider marks are local UI assets: OpenAI's [SIWC white mark](https://developers.openai.com/siwc/website), [OpenRouter's favicon glyph](https://openrouter.ai/favicon/glyph.png), [Anthropic's favicon](https://www.anthropic.com/favicon.ico), and the star cropped from Google's [Gemini API dark logo](https://ai.google.dev/_static/googledevai/images/gemini-api-logo-dark-theme.svg). The Microsoft four-pane mark is rendered as a small SVG. These marks identify the corresponding account providers; they do not claim endorsement.

`niq.png`: 512 px transparent source for the interface. `niq.ico`: Windows sizes 16, 24, 32, 48, 64, 128, 256 px, used by Qt, PyInstaller and NSIS.

Generated with the built-in imagegen tool, then edited with the same tool. Qt produces the size variants without changing the design.
