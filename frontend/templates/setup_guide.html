Proje Kurulum Kılavuzu

İlgili taraflar için adım adım görsel rehber.

Adım 1

SQL Kimlik Doğrulamasını Aktif Et (Mixed Mode)

SQL Server'ın hem Windows hem de SQL kullanıcı ad/parolaları ile giriş kabul etmesi için bu ayarı yapın.

Properties Menüsünü Açma

  1. SSMS (SQL Server Management Studio) açın.
  2. Sol taraftaki 'Object Explorer' panelinde sunucunuza (en üstteki öğe) sağ tıklayın.
  3. Açılan menüden 'Properties' seçeneğine tıklayın.

Security Ayarlarını Yapma

  1. Açılan 'Server Properties' penceresinde sol menüden 'Security' sayfasına gidin.
  2. 'Server authentication' başlığı altında "SQL Server and Windows Authentication mode" seçeneğini işaretleyin.
  3. 'OK' butonuna basarak kaydedin.
  4. Değişikliğin aktif olması için SQL Server servisini yeniden başlatmanız gerekmektedir.
Adım 2

Yeni Kullanıcı (Login) Oluştur

SQL Server'da yeni bir kullanıcı (login) hesabı oluşturmak için aşağıdaki adımları takip edin.

New Login Menüsünü Açma

  1. SSMS (SQL Server Management Studio) açın.
  2. Sol taraftaki 'Object Explorer' panelinde Security klasörünü genişletin.
  3. Logins klasörüne sağ tıklayın.
  4. Açılan menüden 'New Login...' seçeneğine tıklayın.

Login Ayarlarını Yapma

  1. Açılan 'Login - New' penceresinde "SQL Server authentication" seçeneğini işaretleyin.
  2. Login name alanına kullanıcı adınızı girin.
  3. Password ve Confirm password alanlarına parolanızı girin.
  4. "Must change password at next login" kutusunu kaldırın (işaretini kaldırın).
  5. Gerekirse "Enforce password policy" seçeneği açık kalabilir.
  6. Sol menüden 'Server Roles' sayfasına gidin. Genelde sadece 'public' seçili kalır.
  7. 'OK' butonuna basarak kaydedin.
Adım 3

User Mapping ile Veritabanına Bağla ve Yetki Ver

Oluşturduğunuz kullanıcıya veritabanı erişimi ve yetkileri vermek için User Mapping ayarlarını yapın.

User Mapping Sekmesine Geçme

  1. Login penceresinde sol menüden 'User Mapping' sekmesine geçin.
  2. İstediğiniz veritabanını listeden seçin.

Yetkileri Verme

  1. Seçilen veritabanının yanındaki 'Database role membership' bölümünde rol seçimlerini yapın.
  2. 'db_datareader' rolünü işaretleyin (okuma yetkisi).
  3. 'db_datawriter' rolünü işaretleyin (yazma yetkisi).
  4. Tam kontrol isterseniz 'db_owner' rolünü de seçebilirsiniz.
  5. 'OK' butonuna basarak ayarları kaydedin.
Adım 4

Uzaktan Bağlantıya İzin Ver

SQL Server'ın uzaktan bağlantı kabul etmesi için gerekli ayarları yapın.

Uzaktan Bağlantı Ayarlarını Yapma

  1. SSMS (SQL Server Management Studio) açın.
  2. Sol taraftaki 'Object Explorer' panelinde sunucunuza (en üstteki öğe) sağ tıklayın.
  3. Açılan menüden 'Properties' seçeneğine tıklayın.
  4. Açılan 'Server Properties' penceresinde sol menüden 'Connections' sayfasına gidin.
  5. "Allow remote connections to this server" seçeneğinin işaretli olduğundan emin olun.
  6. Eğer işaretli değilse, kutucuğu işaretleyin.
  7. 'OK' butonuna basarak ayarları kaydedin.
